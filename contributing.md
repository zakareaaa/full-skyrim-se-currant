## 🧩 What A Trainer Actually Changes

A trainer edits values the game holds in memory. It is a single-player tool, and
being precise about that keeps expectations correct.

**The categories**

| **Category** | **Examples** |
| --- | --- |
| Resources | currency, materials, ammo |
| Progression | levels, skill points, reputation |
| Survival meters | health, hunger, stamina, temperature |
| Time and speed | game speed, day length |
| World state | item spawns, weather, population |
| Utility | instant build, no weight limit |

**How it works**

The trainer reads the process memory, finds the values behind a given stat, and
lets you write to them. Nothing is injected into the save file unless you enable
persistence.

**Why this is a legitimate product for single-player games**

There is no other player affected, no competitive integrity to protect and no
server to validate against. The entire category exists because players want to
change how their own save behaves.

**What it does not do**

It does not create content that is not in the game, and it cannot affect another
player's session. If you are looking for a multiplayer cheat, this is the wrong
package — the variant for those titles is different.
